# WeQ

面向 QQ NT 聊天记录的本地查看、导出与分析工具。支持消息与媒体浏览、多格式导出、聊天分析、年度报告，以及可选的 QQ 在线能力、AI 助手与 MCP 接入。

[下载 WeQ](https://github.com/weq-devs/WeQ/releases) · [文档站](https://weq-devs.github.io/WeqDocs/) · [快速上手](https://weq-devs.github.io/WeqDocs/guide/getting-started) · [问题反馈](https://github.com/weq-devs/WeQ/issues) · [QQ 交流群](https://qm.qq.com/q/ysMZoAcC1a)
